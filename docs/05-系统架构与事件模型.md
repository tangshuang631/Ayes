# 05 系统架构与事件模型

## 1. 系统模块

第一阶段系统拆分为以下模块：

- 监控目标选择层
- 监控任务编排层
- 目标进程与窗口发现层
- 采集层
- 受控动作层
- 变化检测层
- OCR 与文本结构化层
- 轻量视觉标签层
- 语义匹配层
- 事件抽取层
- 短时时间线存储层
- 长期轻量时间线存储层

## 2. 模块职责

### 2.1 监控目标选择层

- 提供整个屏幕和窗口的候选列表
- 提供缩略图预览
- 绑定进程名、标题和可观测状态
- 支持用户点击选择监控对象

完整交互设计见：

- [17-监控目标选择交互.md](/Users/apple/Desktop/2026/Ayes/docs/17-监控目标选择交互.md)

### 2.2 监控任务编排层

- 接收目标触发监控任务
- 接收观察型监控任务
- 维护任务状态
- 管理 watch spec
- 决定是否启用告警和受控刷新点击

### 2.3 目标进程与窗口发现层

- 识别指定进程
- 枚举关联窗口
- 跟踪窗口生命周期
- 提供跨平台统一窗口发现接口
- 对辅助窗口、装饰窗口和业务窗口做分层过滤
- 提供业务窗口候选集合
- 输出窗口是否具备可观测画面的初步判定

### 2.4 采集层

- 周期性采样
- 记录采样可观测性
- 输出窗口状态
- 提供跨平台统一截图与像素采集接口
- 将“可枚举但不可取像素”的窗口标记为非主链路候选

### 2.5 受控动作层

- 执行用户显式配置的刷新点击
- 记录每次点击动作
- 遵守频率、冷却和开关配置
- 不执行开放式自动操作规划

### 2.6 变化检测层

- 帧差分
- ROI 检测
- 文本块变化检测
- 静态区域跳过
- 相同内容去重

### 2.7 OCR 与文本结构化层

- 提取文字
- 清洗与结构化
- 绑定区域上下文

### 2.8 轻量视觉标签层

- 对变化结果做轻量标签归类

### 2.9 语义匹配层

- 判断事件与监控意图相关性

### 2.10 事件抽取层

- 将原始信号压缩为结构化事件

### 2.11 短时时间线存储层

- 保存最近 5-15 分钟事件
- 保存事件引用关系
- 支持检索

### 2.12 长期轻量时间线存储层

- 保存长期监控期间的低密度摘要事件
- 保留关键状态变化、告警、摘要和时间顺序
- 不保留与短期详细记忆同等密度的完整细节
