# 06 时间线问答与告警

## 1. 时间线问答目标

第一阶段必须支持用户基于最近 5-15 分钟时间线进行提问。

核心问题包括：

- 最近 5 分钟发生了什么
- 最近 10 分钟有哪些异常
- 某个窗口什么时候发生了关键变化
- 为什么当前界面会变成这样
- 哪次变化最值得关注

## 2. 问答路径

建议问答路径如下：

1. 接收问题
2. 将问题转成检索条件
3. 从时间线取回候选事件
4. 补充必要上下文
5. 输出结构化回答

## 3. 问答限制

第一阶段不应采用以下做法：

- 每次问答重新全量 OCR
- 每次问答重新扫描所有截图
- 完全依赖大模型即兴发挥

## 4. 告警目标

第一阶段标准告警出口为企业微信 webhook。

## 5. 告警触发条件

建议包括：

- 命中监控意图
- 事件优先级达到阈值
- 未命中去重限制
- 未命中冷却限制

## 6. 告警内容

告警内容建议包含：

- 时间
- 进程名
- 窗口标题
- 事件摘要
- 关键 OCR 文本
- 事件优先级
- 事件引用 ID

## 7. 第一阶段结论

问答和告警都必须建立在时间线事件之上，而不是建立在原始截图全量重跑之上。
