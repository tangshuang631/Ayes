# Ayes 第一阶段实施方案

- [x] 1. 明确第一阶段技术栈与运行形态
  - 目标：确定 Ayes v1 的语言、运行方式、进程监控方案、OCR 方案、向量检索方案、存储方案、企业微信推送方案。
  - 产出：一份可执行的技术选型结论，回写到正式开发文档或新增正式模块文档。
  - 结果：已新增正式文档 `08-技术选型与运行形态.md`，确定第一阶段采用 Python、本地常驻服务、PyObjC + Quartz/AppKit、跨平台 OCR Provider 抽象、SQLite、企业微信 webhook。

- [x] 2. 验证指定进程下窗口发现能力
  - 目标：验证当前系统环境下，是否可以稳定枚举指定进程关联窗口，并拿到窗口身份、标题、层级、最小化/隐藏等状态。
  - 产出：窗口发现能力结论、限制说明、候选实现路径。
  - 结果：已安装 `PyObjC 11.1` 并完成 macOS 初步验证，可拿到 PID、owner、window number、layer、bounds 和部分 onscreen 状态；但窗口标题常为空，且会混入辅助窗口，因此后续必须加入窗口过滤与业务窗口判定逻辑。

- [ ] 3. 验证窗口采集可行性
  - 目标：验证前台窗口、后台窗口、被遮挡窗口、最小化窗口的像素采集能力边界。
  - 产出：可采集状态矩阵，以及“状态可观测”和“像素可采集”的差异说明。
  - 当前进展：已确认整屏截图可行，窗口级截图为部分可行；同一进程内存在“有元数据但无可抓取画面”的窗口，因此后续必须引入“有画面窗口筛选”规则。

- [ ] 4. 确定采样与变化检测链路
  - 目标：确定采样频率、帧差分方式、ROI 检测方式、去重策略。
  - 产出：变化检测最小链路设计。

- [ ] 5. 确定 OCR 处理链路
  - 目标：确定 OCR 引擎、文本清洗规则、文本块切分规则、与窗口/区域绑定的结构格式。
  - 产出：OCR 输入输出约定。

- [ ] 6. 确定轻量视觉标签策略
  - 目标：明确第一阶段标签集合、标签触发规则、优先级映射。
  - 产出：`dialog`、`error_like`、`status_change` 等标签的初版判定方案。

- [ ] 7. 确定语义匹配方案
  - 目标：明确 embedding 模型、向量库存储方式、事件与 watch intent 的匹配流程。
  - 产出：语义匹配最小实现设计。

- [x] 7.1 完成 OCR Provider 接口设计
  - 目标：定义跨平台 OCR 抽象接口，确保后续 skill 不绑定单一平台。
  - 产出：OCR Provider 输入输出接口、错误模型、能力标识和候选 Provider 优先级结论。
  - 结果：已新增正式文档 `09-OCRProvider接口设计.md`，当前优先实现 PaddleOCR Provider，保留 RapidOCR 和 Tesseract 替换位。

- [x] 8. 完成 Watch Spec 初版定义
  - 目标：把用户自然语言监控目标转成统一可执行配置结构。
  - 产出：可用于实现的 `watch spec` 正式定义。
  - 补充要求：必须支持 `triggered` 和 `observe` 两种模式，并支持可选 `refresh_click` 受控动作。
  - 结果：已新增正式文档 `10-WatchSpec配置契约.md`，包含任务模式、采样/OCR 频率、短期/长期记忆、webhook 和受控刷新点击策略。

- [x] 9. 完成事件模型初版定义
  - 目标：明确事件字段、证据引用、优先级、可观测状态、语义匹配结果。
  - 产出：正式事件 JSON 结构。
  - 结果：已新增正式文档 `11-事件模型契约.md`，定义基础事件结构、事件类型、事件来源、可观测性、证据引用、动作和告警审计事件。

- [x] 10. 确定短时时间线存储设计
  - 目标：明确最近 5-15 分钟事件如何存、如何查、如何清理。
  - 产出：时间线存储结构与清理策略。
  - 补充要求：短期详细记忆默认最多保留 15 分钟。
  - 结果：已新增正式文档 `12-记忆存储设计.md`，明确短期详细记忆默认和最大保留 15 分钟，基于事件和证据引用查询。

- [x] 10.1 确定长期轻量记忆设计
  - 目标：明确长期监控时保留哪些低密度摘要事件、保留多久、如何与短期详细记忆衔接。
  - 产出：长期轻量时间线结构与过期策略。
  - 结果：已新增正式文档 `12-记忆存储设计.md`，明确长期轻量记忆默认保留 24 小时，每 5 分钟生成摘要，保存高优先级事件、告警、状态变化和阶段摘要。

- [x] 11. 确定问答检索路径
  - 目标：定义“最近几分钟发生了什么”“为什么变成现在这样”的检索和摘要流程。
  - 产出：问答链路设计。
  - 结果：已新增正式文档 `13-问答检索路径.md`，明确采用关键词 + 向量混合检索，短期详细记忆负责 15 分钟内细节问答，长期轻量记忆负责 24-72 小时内的持久化回顾，并支持服务或 skill 重启后接续；用户指定时间范围时，检索必须严格限制在该范围内。

- [x] 12. 确定企业微信 webhook 告警策略
  - 目标：明确触发条件、去重、冷却、消息模板和失败重试策略。
  - 产出：告警策略设计。
  - 结果：已新增正式文档 `14-企业微信Webhook告警策略.md`，明确 triggered 模式默认启用、observe 模式默认不主动告警，定义触发条件、去重、冷却、消息模板、失败处理和告警审计事件。

- [x] 12.1 设计受控刷新点击能力
  - 目标：明确用户如何选择点击点、配置频率、暂停点击，以及点击动作如何进入时间线。
  - 产出：刷新点击配置结构、执行边界和审计事件模型。
  - 结果：已新增正式文档 `15-受控刷新点击策略.md`，明确用户显式选点、窗口/屏幕坐标空间、频控、暂停恢复、安全边界，以及 `refresh_click` / `refresh_click_skipped` / `refresh_click_paused` / `refresh_click_resumed` 审计事件。

- [ ] 13. 规划 v1 项目目录结构
  - 目标：在正式实现前明确代码目录、模块边界、配置位置、日志位置、测试目录。
  - 产出：v1 代码结构草案。

- [ ] 13.1 设计监控目标选择交互

  - 产出：目标选择交互说明与数据结构。

- [ ] 14. 拆解第一批开发任务

  - 产出：开发任务清单或正式实施计划文档。
