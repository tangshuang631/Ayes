# 02 产品定位与 MVP

## 1. 项目定位

Ayes 是一个面向人类用户和 AI Agent 的视觉时序回放引擎。

它不是“当前屏幕问答器”，也不是“全量 OCR 工具”，而是一个将指定目标界面变化压缩为结构化事件流的系统。

## 2. 第一阶段目标

第一阶段目标如下：

- 长期监控指定进程下的所有窗口
- 只识别有价值变化
- 保留最近 5-15 分钟短时时间线
- 支持用户提问最近几分钟发生了什么
- 支持企业微信 webhook 推送重点变化

## 3. 第一阶段主用户

第一阶段优先服务：

- 人类用户自己提问回放

不是第一阶段重点的内容：

- 多 Agent 编排
- 大而全的自动化平台
- 通用视觉理解平台

## 4. 产品边界

第一阶段不是：

- 通用桌面自动化平台
- 传统录屏软件
- 全桌面无差别记忆系统
- 复杂工作流系统

第一阶段要做的是：

- 面向指定进程
- 面向短时历史
- 面向重要变化
- 面向结构化事件
- 面向回放与提问

## 5. MVP 必做范围

- 指定进程监控
- 进程关联窗口发现
- 长时运行
- 周期性采样
- 差分检测
- OCR 文本抽取
- 轻量视觉标签
- 语义匹配
- 时间线事件存储
- 企业微信 webhook 告警
- 用户问答回放

## 6. MVP 不做范围

- YOLO 训练与复杂检测模型
- 全桌面监控
- 鼠标键盘自动操作
- 长期历史无限存储
- 复杂多 Agent 编排
- 通用多模态大模型平台化
