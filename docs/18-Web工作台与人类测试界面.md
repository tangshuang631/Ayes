# 18 Web 工作台与人类测试界面

## 1. 文档目标

本文件定义 Ayes 下一阶段必须实现的本地 Web 工作台。

目标不是做宣传页，而是做一个：

- 人类用户可直接使用
- 可直接观察监控效果
- 可直接查看记忆、事件、日志
- 可直接测试问答与条件监控

的工作台界面。

## 2. 定位

Web 工作台是 Ayes 当前阶段的人类主入口。

它必须承担：

- 目标选择
- 监控任务配置
- 监控启动与停止
- 近期事件查看
- 短期记忆查看
- 问答测试
- 运行状态查看
- 日志查看入口

## 3. 布局原则

前端必须：

- 简洁
- 高信息密度
- 少卡片
- 强一体感

推荐结构：

1. 左侧：目标与任务区
2. 中间：近期事件时间线 / 当前截图预览 / 记忆查看
3. 右侧：问答区 / 日志区 / 状态区

页面应优先使用：

- 分栏
- 表格
- 列表
- 时间线
- 分割线
- 抽屉 / 折叠面板

不推荐：

- 卡片瀑布流
- 组件堆砌式 dashboard
- 营销页式大块留白

## 4. MVP 必做界面模块

### 4.1 目标选择区

- 查看屏幕候选
- 查看窗口候选
- 显示预览、进程名、窗口标题、可观测状态
- 点击绑定监控目标

### 4.2 任务配置区

- 选择 observe / triggered
- 调整采样频率
- 配置关键词或简单触发条件
- 配置是否启用 webhook
- 配置是否启用 refresh_click

### 4.3 运行控制区

- 启动监控
- 停止监控
- 显示运行中 / 已停止 / 异常
- 显示当前任务绑定目标

### 4.4 近期事件区

- 展示最近事件时间线
- 支持查看事件类型、时间、摘要、目标、优先级
- 支持查看 OCR 文本摘要

### 4.5 短期记忆区

- 展示最近几分钟的结构化记忆
- 支持按关键词过滤
- 支持按最近 N 分钟过滤

### 4.6 问答区

- 输入问题
- 返回结构化回答
- 显示命中事件与证据引用
- 显示使用的时间范围

### 4.7 日志区

- 查看系统日志
- 查看监控任务日志
- 查看 OCR / capture / diff / alert 相关日志

## 5. 当前阶段验收要求

只有当以下内容成立时，Web 工作台才算达标：

- 用户无需命令行也能完成一次目标选择和监控启动
- 用户能直接看到近期事件
- 用户能直接看到短期记忆
- 用户能直接发起一次问答
- 用户能直接查看近期日志

当前实现还应至少包括：

- 当前截图预览
- 运行状态面板
- 屏幕目标一键加载
- 窗口目标点击加载
- 一次执行采样按钮
- 停止监控按钮

## 6. 与后续 Agent 接入的关系

Web 工作台只是人类入口。

它背后的监控、查询、日志和问答能力必须继续保持服务化边界，供后续：

- skill
- tool
- MCP
- agent

复用。
