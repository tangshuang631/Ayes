Ayes

屏幕感知工作台

以 OCR 为主链路，持续记录目标画面、变化、记忆与告警证据。

开始使用

1. 先在下方选择屏幕或进程目标，确认预览图是你真正想监控的画面。
2. 在任务配置里选择 observe 或 triggered，并框选一个或多个 ROI。
3. 点击“装载任务”，再点“开始持续监控”或“执行一次”。
4. 在右侧查看证据、事件和问答结果；要给 Agent 用时优先走 ayes-agent 或 Ayes skill。
