# Ayes Local 菜单栏手测清单

## 前置条件

```bash
$HOME/.codex/skills/ayes-local/scripts/ayes-agent-local ensure-service
$HOME/.codex/skills/ayes-local/scripts/ayes-menubar-local
```

macOS 右上角应出现 `Ayes ○` 或 `Ayes ◉`。

## 1. 基础菜单

- 点击菜单栏图标，菜单应立即展开。
- 没有任务运行时，顶部应显示未监控状态。
- 有任务运行时，顶部应显示监控中状态。
- 暂停后，顶部应显示已暂停状态。

## 2. 设置

- 点击 `设置...`。
- 设置弹窗不应跳转 Web。
- 修改采样间隔，允许范围 0.5 秒到 1 小时。
- 修改采样质量。
- 切换是否保存 OCR 证据截图。
- 保存后再次打开，值应保持。

## 3. 本地视觉增强

- 打开设置。
- 模型下拉应来自 Ollama 模型列表。
- 选择视觉模型时可启用本地视觉增强。
- 选择非视觉模型时，应提示并自动关闭本地视觉增强。

## 4. 任务列表

- 最近任务列表应显示任务名和目标类型。
- 全屏任务应显示全屏监控。
- 进程任务应显示进程监控和进程名。
- 窗口任务应显示窗口监控和窗口标题或窗口 ID。
- 任务右侧应能打开专属设置、打开任务目录、开始任务。

## 5. 暂停和继续

- 任务运行中点击 `暂停监控`，应一次点击后生效。
- 暂停后按钮应变成 `继续上次的监控`。
- 点击继续后，应一次点击后恢复。

## 6. ROI 创建

- 在某个任务子菜单点击 `设定 ROI...`。
- 即使任务未运行，也应即时采该任务目标截图。
- 框选窗口里的图片方向应正常。
- 拖拽框选后点击下一步。
- 预览确认窗口显示的区域应与框选区域一致。
- 输入 ROI 名称并创建。
- 创建后 `roi list --task-id <task_id>` 应看到 ROI 子任务。

## 7. 目录

- 点击任务的 `打开任务目录`。
- 应打开 `runtime/tasks/<date>/<task_id>/`。
- 如果点击 ROI 子任务目录，应打开 ROI 自己的目录树。

## 8. 快捷键

- 在设置里配置快捷键，例如 `cmd+shift+9`。
- 任务运行中按快捷键，应复制最新采样图并粘贴到当前焦点输入框。
- 如果无反应，检查 `runtime/ayes-menubar.log` 和 macOS 辅助功能权限。
